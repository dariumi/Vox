Vox Studio

Speak with the vox engine on your computer: voices, emotions, dialogue. The page runs here, the speech is made by your engine.

Start the engine and open the link it prints, or paste its address and secret above:

git clone https://github.com/dariumi/Vox && cd Vox && pip install .
vox web --models ./models --voices ./voices

From another computer, start it with --host 0.0.0.0 --tls: an https page can only reach plain http on the same computer.

Voices

A profile is one file with several voices. Each voice has styles (emotions); a style is a recording of how it should sound, an instruction, or both. One profile works on every model: voices are cloned from the recordings where the model can, and mapped to built-in speakers where it cannot.

Models

Models are opened when first used. Device: auto, cpu, gpu, gpu:1, vulkan:0 (add ,codec=cpu etc.).
